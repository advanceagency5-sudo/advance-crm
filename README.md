# AdVance CRM

نسخة تجريبية محلية باللغة العربية — 0.2.0-rc.1.

## التشغيل

يتطلب Node.js 20 أو أحدث. شغّل `npm start` ثم افتح http://127.0.0.1:4173. لا توجد حزم مطلوبة لتشغيل التطبيق.

حساب المدير التجريبي: `moamen` / `demo-admin-only`. حساب العضو التجريبي: `youssef` / `demo-member-only`. هذه حسابات عرض علنية وليست مصادقة آمنة. بيانات العملاء المرفقة اصطناعية.

## الوظائف

إدارة الصفقات والعملات، مهام الفريق وصلاحيات العرض المحلية، خطط المحتوى الشهرية والأسبوعية، احتساب التسليم والاعتماد، وتصدير واسترجاع البيانات. يدعم الهاتف والكمبيوتر. تفاصيل خطط المحتوى في [الدليل](docs/CONTENT_PLANS.md).

## حدود النسخة

البيانات والحسابات محفوظة في متصفح الجهاز فقط، ولا توجد قاعدة بيانات مشتركة أو مزامنة بين الأجهزة أو صلاحيات خادمية. لا تستخدم بيانات حقيقية أو كلمات مرور شخصية. التكاملات الخارجية محاكاة. التنسيق والخطوط تعتمد على خدمات CDN. نشر المصدر على GitHub لا يشغّل نظامًا مشتركًا للفريق.

## الاختبارات

شغّل `npm test` و`npm run check`. تشمل النسخة 26 اختبارًا لمنطق التخزين وخطط المحتوى.

## تجربة الهاتف

شغّل `node build-mobile.cjs` ثم `node mobile-preview.cjs` وافتح العنوان المعروض على هاتف متصل بنفس Wi-Fi. ينشئ البناء ملف HTML تجريبيًا في المجلد الأب. البيانات مستقلة عن نسخة الكمبيوتر.
